# Illustrated POC sources

These are the user's saved, generated REDLINE concept assets, copied intact:

- `boss_mustang_sprite_reference.png`: eight-view black muscle-car reference.
- `passenger-poc-black-hoodie-3view.png`: black-hoodie passenger, three rear views.
- `redline_painted_streetscape_poc.png`: repeated painted roadside buildings.

They are project concept artwork, separate from the original CC0 car sheet in
`../cars/poc/`. See `docs/ILLUSTRATED_ASSETS_POC.md` for extraction, angle coverage
and current prototype limits. The runtime crops are derived in memory; these
source PNGs have not been edited.
